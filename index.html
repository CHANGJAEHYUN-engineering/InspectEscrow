Prototype transparency

이 GitHub Pages 데모의 상태 전이와 AI score는 예선 설명을 위한 인터랙티브 시뮬레이션입니다. 파일 SHA-256은 브라우저 Web Crypto API로 실제 계산하지만, PatchCore 추론·MetaMask·Sepolia·Solidity는 아직 연결하지 않았습니다. 본선 진출 시 동일 UI 흐름을 실제 Python AI와 테스트넷 contract에 연결하는 것이 구현 목표입니다.
