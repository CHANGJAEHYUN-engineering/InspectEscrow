Independent Replay

검사 조건과 증거를 독립적으로 재실행해 결과의 재현성을 확인합니다. Replay 일치가 품질의 정당성을 자동 보증하지는 않습니다.

03

Inspector Decision

재현 가능한 증거와 별도의 판단 근거를 바탕으로 Supplier 지급 또는 Buyer 환급을 서명해 결정합니다.

04

Settlement & Withdrawal

정산 결과를 claimable 잔액에 반영하고 수령자가 직접 Withdraw 합니다. Inspector 응답 불능·Replay 불일치는 별도 예외 경로를 따릅니다.

실증 범위 — 중요

PATCH2 Model A에서는 분쟁·Replay·Backup Inspector·Buyer 환급·인출 경로를 실제 Sepolia에서 실행했습니다. 이번 PATCH3 Model B 신규 S05는 PASS/PASS 정상 경로만 온체인 E2E로 완료했으며, 여기서 표시한 REVIEW 분쟁 경로는 현재 구조 설명입니다.

ADVANCED · TRANSACTION CONSOLE

거래 실행 및 MetaMask 승인

기존에 검증한 PATCH3 실행 엔진을 별도 수정 없이 보존했습니다.

기존 S05 거래는 이미 RELEASED(17)로 종료되었습니다.

새로 촬영한 사진이 자동으로 이 거래에 연결되지 않습니다. 신규 거래·새로운 증거 패키지·유효한 Station 서명·Actor 승인을 확인하기 전에는 거래 실행 버튼을 누르지 마세요.

VALIDATED ENGINE · PRESERVED

검증된 실행 콘솔을 이 화면 안에서 열기

MetaMask 서명, 읽기 전용 사전검증, 실제 테스트넷 거래 승인 기능을 담당하는 기존 콘솔을 불러옵니다. 컨트랙트 또는 서명 로직은 변경하지 않았습니다.
