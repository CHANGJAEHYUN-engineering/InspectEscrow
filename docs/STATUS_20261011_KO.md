## 4. 이번 E2E에서 추가로 실제 검증된 것

Primary Inspector가 기한 내 응답하지 않았을 때 **자동 RELEASE/REFUND하지 않고 Backup Inspector로 failover**하는 경로가 실제로 실행되었다.

또한 Replay는 final settlement 자체가 아니라 `CONSISTENT` gate만 제공했고, 이후 별도 Inspector decision이 있어야 돈의 수령인이 확정되었다. 따라서 역할 분리가 실제 transaction sequence에서 유지되었다.

## 5. Claim boundary

이번 데모가 증명하는 범위:
- 실제 PatchCore output → signed evidence → Sepolia state transition 연계
- frozen policy/model/evidence anchor 사용
- escrow lock과 분쟁 상태
- Primary timeout / Backup failover
- replay consistency gate
- Inspector signed decision
- claimable accounting 및 withdraw
- accounting conservation

증명하지 않는 범위:
- 공개 MVTec 이미지의 실제 제조현장 provenance/custody
- Supplier/Buyer 이미지가 동일 실물이라는 물리적 보증
- Station 서명이 카메라 자체의 무결성을 증명한다는 주장
- controlled artifact-reload replay를 보편적 cross-machine 재현성으로 일반화하는 주장
- AI가 법적/거래상 최종 defect 판정을 자동으로 내렸다는 주장
