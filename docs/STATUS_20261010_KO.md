- **주의:** AI의 이전 `PHASE2_PATCH2_AI_COMPATIBILITY_AUDIT_PATCH2.json`에 기재된 `0x5283badc...`는 과거 모델 해시이며 최종 해시 아님. 이전 `ONCHAIN_UNUSED_TRADE_ID_PREFLIGHT_V1.json`과 `LATEST_SEPOLIA_PREFLIGHT_SESSION_NOTE.json`의 unused 결과는 **거래 제안 이전** 시점의 기록. 현재 동일 `tradeId`는 이미 PROPOSED라서 **재제안 금지**.
- score round-half-up × 10^6. 계약 판단: `< threshold` PASS, `>= threshold` REVIEW. Evidence Package 최종 `evidencePackageHash`는 off-chain AI 증거 하위 artifact의 단순 SHA-256과 동일한 값이라고 가정할 수 없고, 트랜잭션별 Station 서명 preimage 확정이 필요함.

## 4. 완성으로 간주하지 않는 항목
1. Buyer 수락·Inspector 두 명 승인·fund·activate의 실제 Sepolia Receipt.
2. Supplier/Buyer AI evidence와 진짜 EIP-712 Station signature가 결합된 `submitInspection` 실제 Tx.
3. 유효한 독립 Replay 기록 → Inspector 판단 → claimable → withdraw 실제 chain 증거.
4. 공개 MVTec 데이터 시연에서 동일 물리제품의 출하/입고 identity, 실제 provenance/custody 증명.

**멘토링 요청:** 분산 환경의 데이터 출처 신뢰와 AI 재현성을 어디까지 분리/증명할지, Inspector 미응답 및 실행 불일치 시 Fail-safe 경계, AI evidence ↔ wallet protocol의 최소 검증 게이트를 검토 요청.
